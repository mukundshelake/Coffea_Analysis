\section{Introduction}
This document is dedicated to the observables that I want to study/measure in my PhD.
There are mainly three of them $A_C$, $A_{in}$ and $A_{out}$.

\subsection{$A_C$}
This is the asymmetry that was defined for LHC on the same level as $A_{FB}$ in Tevatron.
From the Ref.1, the definitdfion is 

$$A_C = \frac{N(\Delta|y| > 0) - N(\Delta|y| < 0)}{N(\Delta|y| > 0) + N(\Delta|y| < 0)}$$

where, $\Delta|y| = |y_t| - |y_{\bar{t}}|$ is the difference between absolute values of top and anti-top rapidities.



\subsection{$A_{in}$}
From the Ref. \cite{K_hn_2012}, the definition is 

$$A^{in}_{y_0} (y_{0}) = \frac{N(|y_t| < |y_{0}|) - N(|y_{\bar{t}}| < |y_{0}|)}{N(|y_t| < |y_{0}|) + N(|y_{\bar{t}}| < |y_{0}|)}$$


\subsection{$A_{out}$}
From the Ref. \cite{K_hn_2012}, the definition is 

$$A^{out}_{y_0} (y_{0}) = \frac{N(|y_t| > |y_{0}|) - N(|y_{\bar{t}}| > |y_{0}|)}{N(|y_t| > |y_{0}|) + N(|y_{\bar{t}}| > |y_{0}|)}$$
